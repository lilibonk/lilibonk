### pi-pane

**给 pi Coding Agent 开一扇浏览器窗口。**

终端输入 `/web`，浏览器就接上同一个会话。看实时回复、工具调用和代码 diff，也能发消息、传图片。

> 终端继续干活，眼睛换个宽敞工位。

**业务后台的起步包，登录和权限已经到岗。**
