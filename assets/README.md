# Workshop artwork

The day and evening banners are AI-generated pixel illustrations based on
the owner's existing GitHub cat avatar and the approved golden shaded cat
workshop direction. They are illustrations, not photographs of the pet.

- `workshop-day.png`: cream wall, golden daylight and terracotta desk mat.
- `workshop-night.png`: the same scene in warm charcoal evening lighting.
- Source avatar: the public avatar of [lilibonk](https://github.com/lilibonk).

Both banners share a 3:1 composition. The profile selects the evening banner
with `prefers-color-scheme: dark`; the day banner is the fallback. Visible
copy remains in the README so it can wrap on small screens and be read by
assistive technology.

The Apocalypse screenshots and pet preview remain hosted in their original
public project repositories and are linked from the profile README.
