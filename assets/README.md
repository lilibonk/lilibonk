# Workshop artwork

The day and evening banners are AI-generated pixel illustrations in the
approved warm golden workshop direction, using the public GitHub avatar
as a visual reference.

- `workshop-day.png`: cream wall, golden daylight and terracotta desk mat.
- `workshop-night.png`: the same scene in warm charcoal evening lighting.
- Source avatar: the public avatar of [lilibonk](https://github.com/lilibonk).

Both banners share a 3:1 composition. The profile selects the evening banner
with `prefers-color-scheme: dark`; the day banner is the fallback. Each GIF
is 1200 × 400, with an open-eye frame (7,800 ms) and a blink frame (140 ms),
looping continuously. The static PNGs are used for reduced-motion banners.
Visible copy remains in the README so it can wrap on small screens and be
read by assistive technology.

## Blink sources

`animation-source/workshop-day-blink.png` and
`animation-source/workshop-night-blink.png` were edited from the original
banners using the built-in ImageGen tool. Only the eye region at
`left: 1360, top: 338, width: 132, height: 106` is composited onto its
corresponding original. This keeps the surroundings stationary.
The resulting frames are resized with nearest-neighbor sampling and encoded
with Sharp: 256 colors, dither 0.5, effort 10, delays `[7800, 140]`, loop 0.

Edit prompt, applied separately to each original banner:

> Use case: precise-object-edit / identity-preserve. Asset type: one blinking frame for the existing GitHub profile banner animation. Edit the supplied exact 3:1 pixel-art banner. Change ONLY the cat's currently open eye: close that eye into a relaxed curved eyelid matching the style of her other already closed/winking eye. Both eyes are now gently closed for a quick blink. Preserve the cat's head outline, ears, mouth, fur pattern, paws, body and tail; preserve every object, its exact coordinates, every background pixel, the monitor's abstract dashboard, lighting, color palette, framing and aspect ratio. Absolutely no new elements, no shift or zoom, no relighting, no text, no watermark. This frame will be placed next to the original, so pixel-for-pixel layout consistency outside the eye is crucial. Return only the complete edited banner at the same wide aspect ratio, not a contact sheet or diagram.

## Other effects

- `intro-typing-light.svg` and `intro-typing-dark.svg` are generated by
  [Readme Typing SVG](https://github.com/DenverCoder1/readme-typing-svg)
  (MIT) and committed locally, so the profile does not depend on its live
  rendering service. The generated assets embed Fira Code (SIL OFL 1.1).
  Settings: font Fira Code, weight 500, size 18, duration 2800, pause 1600,
  vertical center, 480 × 32, colors `B98232` / `E9BD72`, repeating.
  The upstream copyright notices and licenses are retained in `licenses/`.
- Contribution animations use [Platane/snk](https://github.com/Platane/snk)
  (MIT). The pinned GitHub Actions workflow updates the public graph daily
  and publishes SVGs to `codex/profile-generated`, separate from `main`.
- Release badges use [Shields](https://shields.io/). The build badge is the
  native GitHub Actions status for Apocalypse's main branch.

The Apocalypse screenshots and pet previews remain hosted in their original
public project repositories and are linked from the profile README.
